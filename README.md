# Evidence-first CI/CD writing

把真實 CI/CD measurements、workflow changes、deployment incidents 與
release receipts，整理成有證據邊界的繁體中文技術內容。

## Skill

- [SKILL.md](SKILL.md)
- [Evidence and claim boundaries](references/evidence-and-claim-boundaries.md)

這個 Skill 用來撰寫或審查 CI/CD 案例文章，不會自行修改 Pipeline、合併
Pull Request、部署服務或對外發布內容。

文章草稿不包含在這個公開 repository。
